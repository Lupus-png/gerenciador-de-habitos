# Gerenciador de Hábitos

O Gerenciador de Hábitos é uma aplicação web onde você pode adicionar hábitos a uma lista, marcá-los como concluídos e removê-los quando desejar.

## Funcionalidades

* Adicionar hábitos
* Marcar e desmarcar hábitos como concluídos
* Excluir hábitos
* Armazenar os hábitos no navegador

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* LocalStorage
* JSON

## Como executar

Acesse o projeto através da URL abaixo. Na caixa de texto, digite o hábito que deseja adicionar e clique no botão **"Adicionar"**.

Depois de adicionado, é possível clicar sobre o hábito para marcá-lo ou desmarcá-lo como concluído. Para removê-lo, basta clicar no botão **"Excluir"**.
