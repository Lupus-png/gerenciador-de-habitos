# Gerenciador de Hábitos

O Gerenciador de Hábitos é uma aplicação web onde você pode adicionar hábitos a uma lista, marcá-los como concluídos e removê-los quando desejar.

## Funcionalidades

* Adicionar hábitos
* Marcar e desmarcar hábitos como concluídos
* Editar o nome dos hábitos
* Excluir hábitos individualmente
* Filtrar hábitos por todos/pendentes/concluídos
* Limpar os hábitos concluídos
* Armazenar os hábitos no navegador, mantendo os dados após atualizar a página

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* LocalStorage
* JSON

## Como executar

Acesse a aplicação pelo link da demonstração ou baixe o repositório e abra o arquivo `index.html` no navegador.

## Como utilizar

1. Digite o nome de um hábito no campo de texto e clique em Adicionar.
2. Clique sobre o hábito para marcá-lo ou desmarcá-lo como concluído.
3. Clique em `Editar` para alterar o nome de um hábito.
4. Utilize os filtros para visualizar todos os hábitos, apenas os pendentes ou apenas os concluídos.
5. Clique em `Excluir` para remover um hábito individualmente ou utilize a opção de limpar concluídos para remover todos os hábitos finalizados.
